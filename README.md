# FINE-CNC Fonts Library

A centralized online font collection for FINE-CNC.

## 📚 About

FINE-CNC Fonts Library is a growing collection of fonts maintained for convenient access, backup, and installation across multiple Windows computers.

**Current Collection:** 572+ Fonts

## ✨ Features

- Online font storage through GitHub
- Centralized font collection
- TTF, OTF and TTC support
- Access from anywhere
- Windows 10 and Windows 11 compatibility
- One-command online installation
- Continuous library updates

## 📁 Supported Font Formats

- `.ttf` – TrueType Font
- `.otf` – OpenType Font
- `.ttc` – TrueType Collection

## 🚀 How to Install Fonts

An automated PowerShell installer is being developed.

Once available, installation will be as simple as:

1. Open Windows PowerShell as Administrator.
2. Copy the installation command from this repository.
3. Paste it into PowerShell and press Enter.
4. Wait for the fonts to download and install.
5. Restart your design applications to use the new fonts.

### Planned Installation Command

```powershell
irm https://raw.githubusercontent.com/ofclsuleman/FINE-CNC-Fonts-Library/main/Install-Fonts.ps1 | iex
```

**Note:** This command will become functional once `Install-Fonts.ps1` has been uploaded and tested. Always inspect scripts before executing them.

## 🔄 Updating Fonts

The library will be continuously updated as new fonts are added.

The installer will support downloading newly added fonts without unnecessarily reinstalling unchanged ones.
